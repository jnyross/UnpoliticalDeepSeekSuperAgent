## Marking rules (one point per question; no partial credit)

Accept equivalent plain-English wording. Q1 requires the named area.
Q2 accepts £20.98, £21.0 or £21 per £100 (rounding to the nearest pound);
reject a percentage of a different spending total. Q3 requires £96.9bn
(or the exact source amount). Stating status is not required for Q3, but an
explicitly wrong status is contradictory and scores zero.
Q4 and Q5 need the correct direction; numerical changes are not required.
Q6 requires both amounts with correct labels, each rounded to £0.1bn
(or exact source amounts); “pensions are bigger” alone is insufficient.
Q7 must identify that no home-page values are forecasts; naming linked income
forecasts without distinguishing the home page is insufficient.
Q8 accepts a demonstrated source link and the matching row/cell, or a written
route that identifies Table 5.2 and the Q3 cell. “Government” alone is insufficient.
Missing, ambiguous or contradictory answers score zero. Freeze responses at
the stop time; resolve marking uncertainty against these rules, not with hints.

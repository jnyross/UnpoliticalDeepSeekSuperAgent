Party offers: a 2024 snapshot

These are past plans, not today's plans. The list of Commons parties is from 2024-07-09. Each offer comes from a party's 2024 general election manifesto: its book of plans. We do not say these plans are now law. We do not say they have funds or are still party policy.

We show one tax, benefit or public funding offer per party. Each has the same fields and word limits. Parties are in name order. These are examples, not the full plans. We do not rank them. We use no party colours or scores.

How to read this page

Data period: 2024-07-09. Snapshot as of 2024-07-09. Publish and update dates not supplied.

This is a fixed past snapshot. No next release date is announced.

The offer sums up a party claim. The quote is the party's own text, not our view. We do not judge what the plan would do. We chose text about plans, not sums. We give no cash cost or estimate of funds raised or effects. A missing cost is not zero. “Unavailable here” means this set of data does not give it for this offer. It may exist elsewhere.

The rule is the same for all parties. We pick one direct tax, benefit or public funding pledge. We add a short quote from the source. The text we choose needs no cash cost or estimate of effects. Our choice does not show which policy matters most to a party. Each source is a manifesto from that party. Some saved PDFs come from the British Manifesto Archive, not the party's own site. We label these copies. Where we have not checked a full date, we give just the year. PDF page counts start at the first page, with the cover. We keep the quote's words. We remove line breaks.

Each field has a word limit. The offer can use up to 45 words. The quote can use up to 85. Scope and baseline can each use 30. Year and status can each use 25. Costing and assessment can each use 30. Party names and source page labels can each use 15 words. Source titles can use 35 words. Host labels can use 30. Source web links can use 2,000 characters. The checks use these limits for each party.

The same Commons list has 6 independent MPs. They are not one party. They have no shared party manifesto. We do not give them a joint offer, cost or assessment. We list the Speaker on their own (1 seat). This is not a party offer. We include Sinn Féin by the same rule as all other parties on the Commons list. Checks open the saved Commons list and each PDF. They check that we cover all parties on the list. They check each quote is on the page we cite. They check that file hashes match. A hash is a code used to check a file has not changed. They also check the same fields, order and length limits for all parties. If a source changes, we stop the update for review. We give no outside view on these plans. Each independent assessment field says it is not available here. The same rule applies to all.

How this log works

Each entry gives the date the fix was applied, the page, the error and the fix. It links to the change as evidence. The same source checks apply to all parties.

We add entries at the end. We do not change or remove old entries. If an entry is wrong, we add a new one that names it and explains the fix. Routine data updates and new features are not corrections.

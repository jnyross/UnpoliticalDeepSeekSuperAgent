About this project

How this site is made, what we know about the project, and how to report an error.

Report an error

Report an error on GitHub. You need to sign in to a GitHub account to submit a report. You can read public reports without an account.

Give the page link, the figure or text at fault, and a source that helps us check it. For a display fault, add your screen size and browser. Reports are public: do not include private or sensitive details. This route does not promise a reply time.

Methods and limits

This is a static site. Its core pages work with JavaScript off. Code reads retained source files and builds the pages and open data. Checks compare figures with source cells and file hashes before new pages replace the last good output.

Spending sources and methods, tax, borrowing and debt, spending history and party offers give their own dates, scope and source links. Party offers are a dated 2024 snapshot, not current plans. Missing values are not zero. Different totals and source dates must not be mixed.

The overview uses HM Treasury's Public spending statistics: July 2026, source updated 2026-07-29. Other pages keep their own source dates. See the README for the rebuild command and full methods and the checks and code. Open JSON, CSV and retained raw files are linked beside the figures.

Automated checks are not tests with real users. No claim of human review or a full rubric level is made here.
